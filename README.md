# Wydania (Grabski Studio)

Wewnętrzna aplikacja macOS Grabski Studio: tłumaczenie PDF-ów (polski ⇄ hiszpański ⇄ angielski) z zachowaniem wyglądu.
To repozytorium zawiera **tylko paczki do instalacji i pliki aktualizacji** — bez kodu źródłowego.

## Instalacja (pierwszy raz)
1. Otwórz najnowsze wydanie: **Releases → najnowsza beta** i pobierz `Tlumacz-beta-N.zip`.
2. Kliknij dwa razy ZIP, przeciągnij **Tłumacz** do folderu **Aplikacje**.
3. Pierwsze uruchomienie: macOS zatrzyma apkę (nie pochodzi z App Store). Wybierz **Gotowe**, potem
   **Ustawienia systemowe → Prywatność i ochrona → Otwórz mimo to**. Robisz to tylko raz.
4. Wpisz **kod dostępu**, który dostałeś od Krzycha (raz). Potem apka poprowadzi Cię dalej (powitanie i „Pierwsze kroki”).

## Aktualizacje
Kolejne bety apka znajdzie sama (**Tłumacz → Sprawdź aktualizacje…**). Pokaże listę „co poprawione” i zainstaluje się po zamknięciu.
Tłumaczenia, ustawienia i klucz zostają. Każda paczka jest podpisana — apka odrzuci plik, którego nie podpisał autor.

Wymagania: Mac z procesorem Apple (M1 lub nowszy), macOS 15 lub nowszy.
